# CareerConnect — LinkedIn-Inspired HTML/CSS College Demo

This is a static, educational recreation inspired by the general layout patterns of a professional networking site.

## Technologies
- HTML5
- CSS3

No JavaScript, frameworks, backend, database, or build tools are used.

## Pages
1. `index.html` — Home / Feed
2. `network.html` — My Network
3. `jobs.html` — Jobs
4. `messaging.html` — Messaging
5. `profile.html` — Profile

## How to run
1. Extract the folder.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Use the top navigation to move between pages.

## Important
Buttons, search boxes, messaging, job search, and other controls are visual/static examples. They do not perform real actions because JavaScript/backend code was intentionally excluded.

## Main CSS concepts used
- CSS variables
- Flexbox
- CSS Grid
- Responsive media queries
- Cards
- Sticky navigation
- Borders and shadows
- Typography hierarchy
- Responsive layouts
